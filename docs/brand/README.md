# Stack app branding

The current showcase uses the original black layered Stack mark on mint green from the historical iOS branding export, `stack_logo_light@3x.png`.

- `original-app-logo.png`: unchanged original export.
- `profile-panel.png`: landscape presentation adapted from that original with the built-in image-generation tool on October 10, 2026. The original export remains the source of truth for the mark.
- `logo.png`: superseded blue concept, retained only for history; do not use for current branding.

Stack is the consumer investing-app project. Do not substitute Stack Labs corporate branding or the dollar-symbol and green-box concepts preserved in older source snapshots.

## Adaptation prompt

Edit the supplied original Stack app logo into a 1536x1024 landscape GitHub profile card. Preserve the EXACT black outlined three-layer Stack glyph from the reference, with its proportions, rounded strokes and open lower layers unchanged. Preserve the reference's flat pale mint green background, extending it to fill the entire card edge to edge. Center the glyph prominently, approximately 54% of canvas height. No text, no new logo, no gradients, no shadows, no border. This is a faithful presentation adaptation of an existing brand, not a redesign.
